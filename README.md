# [Bài tập] Tạo bảng danh sách sản phẩm trong HTML

Dự án bài thực hành tạo bảng danh sách sản phẩm chuẩn HTML5 kết hợp giao diện thiết kế hiện đại, sang trọng và responsive.

## 📌 Mục tiêu bài tập
- Luyện tập sử dụng cấu trúc bảng HTML với các thẻ chuẩn: `<table>`, `<tr>`, `<th>`, `<td>`.
- Hiển thị danh sách sản phẩm gồm đầy đủ thông tin: **Tên sản phẩm**, **Giá**, **Số lượng**.
- Bổ sung tối thiểu 4 sản phẩm theo đúng yêu cầu đề bài (thực tế triển khai 6 sản phẩm đa dạng).

## 🛠 Cấu trúc mã nguồn
- `index.html`: Chứa toàn bộ mã nguồn HTML5, tiêu đề `<h1>Danh sách sản phẩm</h1>`, cấu trúc bảng `<table>` chuẩn mực và phong cách CSS hiện đại cùng tính năng tìm kiếm sản phẩm nhanh (Live Search).

## 🌟 Điểm nổi bật
- **Giao diện hiện đại**: Sử dụng bảng màu Indigo/Slate, phông chữ Google Fonts (Plus Jakarta Sans).
- **Responsive Web Design**: Tự động tương thích và co giãn tối ưu trên mọi màn hình máy tính, máy tính bảng và điện thoại.
- **Tương tác trực quan**: Hiệu ứng hover nổi bật trên từng dòng, phân loại danh mục sản phẩm, tính tổng tự động ở thẻ `<tfoot>`.
- **Tìm kiếm tức thì**: Tích hợp ô lọc sản phẩm thời gian thực.
